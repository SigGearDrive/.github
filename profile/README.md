# SigGear | Custom Precision Transmission Manufacturing

**SigGear develops and manufactures custom precision transmission solutions for robotics, automation and compact motion systems.**

The public products and engineering files in this GitHub organization are **reference platforms**, not the full scope of SigGear's work. Many customer-specific transmissions, robot-joint configurations, drawings and production programs remain confidential under NDA or other confidentiality agreements.

SigGear's core capability is to help engineering teams move from a real transmission problem to a manufacturable solution:

**Requirement / Existing Motor / Drawing / Failed Gearbox**  
→ **Engineering Review**  
→ **Prototype / Sample**  
→ **Application Validation**  
→ **Design Refinement**  
→ **Design Freeze**  
→ **Pilot Preparation**  
→ **Repeatable Volume Manufacturing**

## Start With What You Already Have

A project does not need to begin with a SigGear model number.

You may already have:

- **a motor** that must be retained
- **a drawing or CAD model** that defines the mechanism
- **an existing gearbox / reducer that keeps failing**
- **a prototype requirement followed by future volume production**
- a target torque / speed
- a fixed installation envelope
- a special shaft, flange or mounting interface
- a robot joint concept
- an encoder / driver / communication requirement

[**Start a Custom Transmission Review**](https://siggeardrive.github.io/SigGear-product-docs/custom-engineering/start-with-your-problem/)

## Custom Engineering & Manufacturing

SigGear can review, subject to engineering feasibility:

- custom planetary gearheads
- custom cycloidal reducers
- robot joint modules and compact actuators
- motor + gearhead integration
- customer-motor interface matching
- reduction ratio
- input pinion / shaft
- output shaft / flange
- housing and mounting features
- bearing / external-load arrangement
- encoder, driver, cable and connector integration where applicable
- prototype-to-production configuration development

For applicable production programs, SigGear supports repeatable manufacturing, inspection, production planning and batch delivery after the configuration is confirmed.

Actual lead time, quantity and production plan are project-specific.
